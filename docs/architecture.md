# 구성

## 한 파일 안의 구성

`index.html` 하나가 세 덩어리로 되어 있다.

- `<style>`: `:root`의 색·모서리 기준값(`--bg` 상아, `--surface-alt` 베이지, `--accent` 카라멜, `--radius-*`)과 `fd-`로 시작하는 클래스들.
- 본문 마크업: 머리말(제목·요약 줄·백업 버튼), 위쪽 바꾸기(다녀온 곳 / 가고 싶은 곳), 검색창, 종류 칩, 개수·지도 버튼·정렬, 목록(`#fd-list`), 아래 "＋" 버튼, 숨은 파일 입력 두 개(사진, 백업), 알림.
- `<script>` **한 블록**: 즉시 실행 함수 하나 안에 앱 전부가 있다. 순서는 대략 카카오 키 상수 → 작은 도구 → 데이터 정리·읽기·쓰기 → 사진 저장소 → 상태 → 목록 그리기 → 시트 → 가게·방문 화면 → 폼 → 카카오(불러오기·위치 검색·지도) → 가고 싶은 곳 → 백업 → 알림 → 이벤트 연결 → 첫 `render()`.

## 데이터가 사는 곳

| 저장소 | 무엇 | 언제 읽고 쓰나 |
|---|---|---|
| `localStorage['fd_data_v2']` | 가게(방문 포함)와 가고 싶은 곳 전부, JSON 하나 | 앱을 열 때 한 번 읽어 `state`에 둔다. 바뀔 때마다 통째로 다시 쓴다 |
| `localStorage['fd_data_v1']` | 1판 원본 | `fd_data_v2`가 없을 때 한 번 읽어 옮긴다. 쓰지 않는다 |
| IndexedDB `fd_photos`, store `photos` | 사진 `{id, full, thumb}` (둘 다 JPEG Blob) | 사진을 넣을 때 쓰고, 화면에 보일 때 읽어 objectURL로 바꿔 둔다 |

글 기록과 사진을 나눈 이유: localStorage는 문자열만 담고 용량이 몇 MB라서 사진을 넣을 수 없다. 기록 JSON에는 사진 id만 들어간다.

## 화면을 그리는 두 방식

1. **목록은 문자열로 통째로 다시 그린다.** `render()`가 위쪽 바꾸기·요약 줄·종류 칩·목록을 다시 그리고, 검색창에 글자를 칠 때는 `renderList()`만 부른다. 검색창 자체는 어느 경우에도 다시 그리지 않는다.
2. **시트(전체 화면 겹침)와 폼은 바뀐 부분만 고친다.** 가게 화면·방문 폼·가고 싶은 곳 폼·지도는 `openSheet`로 한 번 만들고, 이후에는 별·칩·메뉴 줄·같은 가게 알림·위치 상자처럼 바뀐 노드만 바꾼다. 메뉴 줄 추가는 줄 하나를 덧붙이고, 빼기는 그 줄만 없앤다.

시트는 겹쳐 열린다(가게 화면 위에 방문 폼, 지도 위에 가게 화면). 저장이 끝나면 목록은 `render()`로, 열려 있는 가게 화면은 그 화면만 다시 채운다.

## 대표 흐름: 새 맛집 기록

1. "🍴 맛집 기록하기" → 새 가게 모드의 방문 폼이 열린다(가게 칸 + 방문 칸).
2. 이름 칸에서 손을 떼거나 위치를 고르면 같은 가게 후보를 찾아 알림 자리만 바꾼다. "이 가게에 방문으로 추가"를 고르면 같은 폼이 그 가게의 새 방문 모드로 바뀐다.
3. 사진을 고르면 캔버스로 줄여(긴 변 1600px, 정사각 360px) IndexedDB에 바로 넣고 id를 폼에 붙인다. 취소하면 이번에 넣은 사진만 지운다.
4. 저장 → 폼 값을 가게·방문에 옮기고 둘 다 `updatedAt`을 갱신 → `fd_data_v2`에 통째로 쓰기 → 쓰기가 실패하면 바꾸기 전 상태로 되돌린다 → 목록 다시 그리기 → 알림.

## 카카오 지도

- 스크립트는 위치 검색이나 지도를 처음 쓸 때 `loadKakao()`가 `<script>` 요소를 만들어 넣고(`libraries=services&autoload=false`), `kakao.maps.load`로 시작한다. 앱을 열 때는 불러오지 않는다.
- 위치 검색은 `kakao.maps.services.Places().keywordSearch`, 지도는 `kakao.maps.Map` 위에 `CustomOverlay`로 그린 이모지 핀이다.
- 키가 없거나 인터넷이 안 되거나 불러오기에 실패하면 그 자리에만 안내가 뜨고 기록·보기·백업은 그대로 된다.

## 바깥과 주고받는 것

- 카카오: 장소 검색 요청과 지도 타일. 사용자가 위치 검색이나 지도를 쓸 때만 나간다.
- 백업 파일: 사용자가 직접 공유 시트(폰) 또는 내려받기(컴퓨터)로 내보내고, 파일 고르기로 불러온다.
- 그 밖에 기록이 기기 밖으로 나가는 길은 없다.

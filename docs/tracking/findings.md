# 아직 못 푼 문제

## 실제 카카오 SDK로 위치 검색·지도를 확인하지 못했다

- **무엇**: 위치 검색(`keywordSearch`)과 지도(`Map`, `CustomOverlay`, `setBounds`)는 페이지에 넣은 가짜 `window.kakao`로만 흐름을 확인했다. 실제 SDK에서 결과 필드 모양, 핀 위치(`yAnchor`), 여러 핀 맞추기, 8초 시간 초과 경로는 확인되지 않았다.
- **왜 중요한가**: 사용자가 지도를 고른 이유가 "가게 이름으로 검색해 위치가 자동으로"다. 여기서 어긋나면 위치·지도 기능 전체가 안 된다(기록 자체는 영향 없음).
- **왜 지금 못 푸나**: 카카오 JavaScript 키가 없다. 키 발급과 도메인 등록은 사용자 계정으로만 할 수 있다.
- **풀 방법**: 키를 넣은 뒤 `http://localhost:4175`(등록 도메인)에서 검색 → 고르기 → 저장 → 지도 열기 → 핀 누르기를 한 바퀴 해 보고, 실제 주소에서도 한 번 본다.

## 실제 아이폰에서 이름 칸 손 떼기를 확인하지 못했다

- **무엇**: 같은 가게 알림은 이름 칸의 `focusout`(또는 `change`)에서 돈다. 미리보기 창에서는 이벤트를 직접 보내서 확인했다.
- **왜 중요한가**: 아이폰에서 이 이벤트가 기대대로 오지 않으면 같은 가게 알림이 뜨지 않아 같은 가게가 두 개 생길 수 있다(지우기로 되돌릴 수 있는 수준).
- **왜 지금 못 푸나**: 실제 기기에서만 확인할 수 있다.
- **풀 방법**: 홈 화면 앱에서 이미 있는 가게 이름을 치고 다음 칸을 눌러 알림이 뜨는지 본다.

# 0004 글 기록은 localStorage, 사진은 IndexedDB

## 상황

서버 없이 기기 안에 기록과 사진을 모두 담아야 한다. 사진은 한 장에 수백 KB이고 기록마다 최대 10장이다.

## 결정

글 기록 전체는 localStorage의 JSON 하나(`fd_data_v2`)에, 사진은 IndexedDB(`fd_photos`)에 Blob으로 둔다. 사진은 넣을 때 큰 것(긴 변 1600px)과 정사각 미리보기(360px)로 줄인다.

## 고르지 않은 것

- **모두 localStorage**: 용량이 몇 MB라 사진 몇 장이면 꽉 찬다.
- **모두 IndexedDB**: 글 기록 읽기·쓰기가 전부 비동기가 되어 화면 코드가 복잡해지고, 형제 앱(가계부)과 다른 방식이 된다.

## 결과

- 백업 파일은 두 저장소를 모아 사진을 data URL로 넣는다(파일이 커진다).
- 기록을 지울 때 사진은 따로 지워야 하고, 다른 방문이 쓰는 사진을 지우지 않도록 확인해야 한다.
- 두 저장소가 따로라서 기록 JSON에는 있는데 사진이 없는 경우가 생길 수 있다(그 사진 자리만 빈다).

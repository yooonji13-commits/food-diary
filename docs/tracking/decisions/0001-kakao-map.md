# 0001 지도는 카카오 지도로 한다

## 상황

기록한 가게를 앱 안 지도에 핀으로 모아 보고 싶다는 요청이 있었다. 앱 안에 지도를 띄우려면 지도 회사의 키가 필요하고, 가게마다 위치(위도·경도)를 얻을 방법도 필요했다. 사용자는 평소 네이버 지도를 쓴다.

## 결정

카카오 지도 JS SDK와 장소 검색(services)을 쓴다. 가게 이름으로 검색해 고르면 위치·주소·분류가 함께 들어온다.

## 고르지 않은 것

- **네이버 지도**: 평소 보던 지도 모양이지만, 웹에서 쓸 수 있는 가게 이름 검색이 없어(지역 검색 API는 서버에서 비밀 키로만 부를 수 있다) 위치를 지도에서 직접 찍거나 주소를 쳐야 한다. 네이버 클라우드 가입도 더 번거롭다.
- **가입 없는 공개 지도**: 키 없이 바로 되지만 가게 검색이 없고 한글 지명·가게 표시가 부족하다.

## 결과

- 사용자가 카카오 개발자 키를 받아 도메인을 등록해야 지도·검색이 동작한다. 키가 없어도 기록은 다 된다.
- 위치 형식에 카카오 장소 id가 들어가고, 같은 가게 판단이 이 id에 기댄다. 다른 지도로 바꾸면 기존 위치의 id는 같은 가게 판단에 쓸 수 없게 된다.
- 지도 모양이 사용자가 평소 보는 네이버와 다르다. 이 점을 알고 고른 것이므로 "네이버로 바꾸자"고 되돌리지 않는다.

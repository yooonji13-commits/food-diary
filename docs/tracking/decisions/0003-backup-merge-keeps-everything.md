# 0003 백업 불러오기는 지우지 않고 합친다

## 상황

기기를 옮기거나 다시 설치할 때 백업 파일을 불러온다. 불러올 파일이 기기의 기록보다 오래되었을 수도, 새로울 수도 있다. 동기화가 없으므로 "지운 것"을 기기 사이에 알릴 방법이 없다.

## 결정

불러오기는 더하기만 한다. 같은 id는 `updatedAt`이 늦은 쪽을 쓰고, 방문은 id로 합쳐 양쪽 것을 다 남긴다. 기기에 있는 기록은 지우지 않는다. 단, 이미 다녀온 곳으로 옮긴 가고 싶은 곳(어떤 가게의 `fromWishIds`에 있는 id)은 되살리지 않는다.

## 고르지 않은 것

- **백업 내용으로 통째로 바꾸기**: 백업 이후에 쓴 기록이 사라진다.
- **지운 기록 표시(지움 표식)를 남겨 불러올 때도 지우기**: 지운 기록이 되살아나지 않지만, 표식을 계속 들고 다녀야 하고 잘못된 파일 하나로 기기 기록이 지워질 수 있다.

## 결과

- 예전에 지운 가게·방문이 백업에 남아 있으면 불러올 때 되살아난다(사용자가 다시 지우면 된다). 잃는 쪽보다 낫다는 사용자 선택이다.
- 미래 날짜의 `updatedAt`이 든 파일은 기기의 같은 기록을 바꿀 수 있어서, 확인 문구에 "더 최근 것으로 바뀌는 기록" 수를 보여 준다.

# 0002 같은 가게는 위치를 먼저 보고, 이름만 같으면 묻는다

## 상황

같은 가게에 방문을 쌓으려면 새로 쓰는 기록이 이미 있는 가게인지 알아봐야 한다. 그런데 스타벅스·교촌치킨처럼 이름이 같은 지점이 많고, 반대로 같은 가게를 조금 다르게 적을 수도 있다.

## 결정

둘 다 카카오 위치가 있으면 카카오 장소 id가 같을 때만 같은 가게로 본다. 한쪽이라도 위치가 없으면 이름(공백·대소문자 무시)이 같을 때 확정하지 않고 "혹시 같은 가게인가요?"라고 물어본다. 후보가 여럿이면 목록으로 보여 고르게 한다.

## 고르지 않은 것

- **이름만으로 판단**: 지점이 다른 같은 이름 가게가 한 가게로 합쳐져 방문 기록과 지도 핀이 섞인다.

## 결과

- 위치 없이 저장한 가게는 이름이 같아도 자동으로 합쳐지지 않고 늘 사용자에게 묻는다.
- 1판에서 옮긴 기록은 이름이 같아도 합치지 않는다(사용자가 필요하면 직접 정리).

# 현황

## 된 것

| 기능 | 상태 |
|---|---|
| 상아·베이지 + 카라멜 디자인, 음식 이모지, 새 앱 아이콘 | 만들고 375px 미리보기에서 확인함 |
| 저장 형식 2판, 1판 기록·1판 백업 옮기기 | 만들고 확인함(`fd_data_v1` 그대로, 같은 1판 백업 두 번 불러와도 중복 없음) |
| 백업 2판 내보내기·불러오기·합치기 | 만들고 확인함(지우고 다시 불러와 사진까지 복구, 옮긴 가고 싶은 곳 되살아나지 않음) |
| 가게 하나에 방문 여러 번, 목록 별점·정렬·요약 줄 | 만들고 확인함 |
| 또 갈래요(가게 화면·새 방문에서만 바뀜) | 만들고 확인함 |
| 방문·가게 지우기, 마지막 방문 → 가게까지, 되돌리기 | 만들고 확인함(되돌리기 중 다른 알림이 떠도 버튼 유지) |
| 같은 가게 알림(이름 기준·위치 기준) | 만들고 확인함. 위치 기준은 가짜 카카오 객체로만 확인 |
| 가고 싶은 곳(넣기·고치기·지우기·다녀왔어요) | 만들고 확인함 |
| 카카오 위치 검색, 종류 자동 고르기 | 만들고 가짜 카카오 객체로만 확인. **실제 카카오로는 확인하지 못함**(키 없음) |
| 지도(두 색 핀, 거르기 적용, 핀 카드) | 만들고 가짜 카카오 객체로만 확인. **실제 지도로는 확인하지 못함**(키 없음) |
| 키가 없을 때 안내 | 확인함(요청을 보내지 않고 나머지 동작) |
| GitHub Pages 배포 | `https://yooonji13-commits.github.io/food-diary/` |

자동 테스트는 없다. 위 "확인함"은 브라우저 375px 미리보기에서 직접 눌러 본 결과다. 실제 아이폰에서의 손 떼기(이름 칸에서 벗어날 때의 같은 가게 확인)는 확인하지 못했다.

## 남은 것 (순서대로)

1. 사용자가 카카오 JavaScript 키를 받아 도메인을 등록하고 `KAKAO_JS_KEY`에 넣기 → 실제 위치 검색·지도 확인.
2. 실제 아이폰에서 홈 화면 앱으로 한 바퀴 써 보기(사진 넣기, 백업 공유 시트, 같은 가게 알림).
3. (사용자가 원하면) 여러 기기 동기화.
4. (사용자가 원하면) 지금 위치에서 가까운 순으로 보기, 네이버 지도 앱으로 바로 열기.
